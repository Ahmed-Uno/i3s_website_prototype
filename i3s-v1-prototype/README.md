# I3S V1 — Static Website Prototype

## Run
Open `index.html` directly in a modern browser.

No backend, database, CMS or build step is required.

## Pages
- Home
- About
- Solutions
- Contact

Navigation uses URL hash routing (`#/`, `#/about`, `#/solutions`, `#/contact`).

## Notes
- Content is based on the I3S brochure supplied for this prototype.
- The contact form is visual only.
- Hero/industry photos use remote Unsplash URLs for the prototype.
- The `28+ years` figure is marked for verification before production.
- Partner brands are listed as text/context and should be verified before publishing representation/exclusivity claims.
